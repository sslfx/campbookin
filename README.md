# CampBookin API

CampBookin — микросервисная платформа для бронирования путевок в детские лагеря. 
Система позволяет пользователям регистрироваться, логиниться, а после просматривать лагеря и смены. Директора могут 
управлять лагерями, сменами и автоматически рассылать им электронные путевки (PDF-билеты) на почту при бронировании.

# Архитектура проекта

Проект построен на базе микросервисной архитектуры. Общение между сервисами внутри сети происходит по протоколу gRPC, 
а наружу выставлен REST API через Gateway.

API Gateway: Точка входа. Маршрутизирует HTTP-запросы, переводит их в gRPC и отправляет нужным сервисам.
Registration Service: Отвечает за аутентификацию, регистрацию пользователей и выдачу JWT-токенов. 
Admin Service: Управление бизнес-логикой. CRUD-операции для лагерей и смен, назначение директоров, а также создание событий о новом бронировании.
Notification Service: Асинхронный воркер. Слушает очередь сообщений Kafka, генерирует PDF-путевки и отправляет email-уведомления пользователям.

# Инфраструктура
PostgreSQL: Основная  база данных.
Redis: Кэширование запросов для снижения нагрузки на БД.
Kafka: Брокер сообщений для асинхронной генерация  и отправки путевки.
Nginx: Прокси для маршрутизации внешнего трафика.
